# ────── PitchGrill ──────
> **An AI Investor Panel That Grills Your Pitch — and Fact-Checks You Live**

PitchGrill is a production-grade multi-agent pitch simulator. Pitch your startup idea to receive real-time follow-up questions from three distinct investor personas, get your factual claims checked live against the web, and receive structured evaluation feedback.

### 🛠️ Tech Stack
* **Backend:** FastAPI, Python 3.11+, SQLAlchemy, MySQL
* **AI & Agent Orchestration:** LangGraph, LangChain, ChromaDB (RAG)
* **Search Integration:** Tavily / Serper API
* **Frontend:** React.js, TailwindCSS
